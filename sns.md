# Amazon SNS


* I created an SNS topic named `HomeAlertTopic`
* I added email subscription and confirmed it
* I copied the topic ARN and used it in Lambda
* I enabled SNS publish logic in Lambda
* I tested alerts by sending fire and smoke data

## Result

Email alerts were successfully received for critical conditions.
